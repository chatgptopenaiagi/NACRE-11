# Changelog

## 0.1.0 — initial experimental public release

- Published the independent Nacre lexer/parser, nominal type checks, checked dependency IR and bounded interpreter.
- Retained immutable values, typed tasks, verification postconditions, modules, structured errors, explicit retry policy and pure-node checkpoint reuse.
- Made the portable core and SQLite usable without GENESIS projects or developer-specific directories.
- Added configurable optional bridges, capability availability metadata, working-directory workspaces and a public CLI entry point.
- Added wheel/source packaging, standalone target-specific distributions, portable examples and release acceptance.
- Included parser/domain-contract regression fixes from the experimental prototype.
- Made checkpoint implementation identities stable across fresh-process hash seeds, including Python 3.10, and verified canonical workspace paths on Windows runners.

This public release is derived from the existing 0.1.0 research prototype. Historical workstation integration and benchmark counts apply to their recorded environment, rather than every public installation.
